Учебная гонка — редактор и игра

Файлы:
- index.html — редактор. Открывается первым.
- game.html — сама игра. Редактор показывает её справа и формирует ссылку для Genially.
- assets/ — изображения дороги и машин.

Работа с редактором:
1. Откройте index.html.
2. Настройте правила и задания слева.
3. Справа отображается живое меню игры.
4. Кнопка «Скопировать код» копирует iframe для Genially.
5. Кнопка «Скачать HTML» создаёт игровую HTML-страницу с текущими настройками.

Важно для Genially:
Сначала опубликуйте весь архив на GitHub Pages. Кнопка копирует ссылку на game.html с настройками в адресе.

Важно для скачанного HTML:
Файл uchebnaya-gonka.html использует изображения из папки assets, поэтому при переносе положите его рядом с папкой assets.

Логика жизней:
Каждые заданные в редакторе N очков создают бонус одной жизни. Если все сердца заполнены, бонус хранится и автоматически восстанавливает сердце после следующего столкновения.
