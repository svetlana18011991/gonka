Как заменить игру на GitHub Pages:
1. Распакуй архив.
2. Удали старые index.html и папку assets из репозитория.
3. Загрузи новый index.html и новую папку assets целиком.
4. Дождись публикации GitHub Pages.
5. Открой страницу и нажми Ctrl+F5, чтобы браузер не использовал старые картинки из кэша.
